# Smile Slice

A neon 3D rhythm game by Smiles 2322. Swipe glowing blocks to the beat of Tammy Michelli songs, or add any MP3 or WAV and Smile Slice builds Easy, Normal and Hard levels for it. No ads, no accounts, and everything stays on your device.

Play: https://smiles2322-cmd.github.io/smile-slice/

Music: "Oxygen You" and "Flip Flop State of Mind" by Tammy Michelli. All rights reserved.
